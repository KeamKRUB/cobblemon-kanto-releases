# Cobblemon Kanto

ไฟล์ติดตั้งและอัปเดตสำหรับผู้เล่น Cobblemon Kanto

- **Cobblemon-Online-Installer.exe** — สำหรับคนที่ยังไม่เคยติดตั้ง
- **Cobblemon-Client-Update.exe** — อัปเดตการติดตั้งเดิมจาก Installer รุ่นก่อน โดยเก็บบัญชี การตั้งค่า สกรีนช็อต และ Replay ที่มีอยู่
- **Cobblemon-Online-Payload.zip** — แพ็กที่ Installer และ Update ดาวน์โหลดให้อัตโนมัติ

ตัวติดตั้งและตัวอัปเดตปกติไม่ติดตั้ง ReplayMod ผู้ที่มี ReplayMod อยู่แล้วสามารถเก็บไว้ใช้ต่อได้

ดูไฟล์พร้อมใช้งานในหน้า **Releases** และปิดเกมกับ Launcher ก่อนอัปเดต

Minecraft, Cobblemon, and bundled third-party mods remain the property of their respective authors. Credits and licenses are included in the client package where provided. Author-hosted add-ons are downloaded from their official distribution URLs.

The workflow reconstructs the verified release ZIP from the existing public base and a small binary transport patch, then checks its SHA-256 before uploading. It contains no account credentials or private server data.
